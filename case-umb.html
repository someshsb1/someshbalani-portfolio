Case Study

UMass Boston Visualization (Tableau)

A Tableau dashboard that turns campus comparison data into a guided view for stakeholder review.

Tableau Dashboard design Stakeholder reporting
View project Source code
Role

Analyst + storyteller

Defined the key comparisons, cleaned the inputs, and designed the dashboard narrative.

Tools

Tableau, Excel

Created interactive dashboards and summaries optimized for quick insight.

Focus

Stakeholder clarity

Designed the visuals to help reviewers compare groups without inspecting every row.

Project Breakdown

Problem

Campus metrics needed a clearer comparison layer

Raw comparisons were difficult to scan quickly, especially for stakeholders looking for differences across groups.

Data

Faculty and coaching comparison data

Organized the project data around the comparisons a reviewer would naturally make when evaluating patterns.

Method

Guided Tableau dashboard

Used filters, summaries, and annotations to make the dashboard useful for both quick scans and deeper review.

Result

Clearer stakeholder review

The dashboard brings the most meaningful differences forward through filters, summaries, and visible context.

Highlights

Guided exploration

Filters and drill-downs help the viewer explore the data without getting lost.

Clear next step

Add a summary page that ranks the largest differences, cites the data source, and explains key filters up front.
